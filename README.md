A make.fun bounty entry: one line of famous last words, a tombstone
epitaph of at most 150 characters, written to `/output/entry.txt`.

## The line

> I spent my life trying to get the last word. It was 'ouch'.

A lifetime spent fighting for the last word, and the last word turns
out to be the most pathetic word possible. The joke lands on the
last word, reads like something carved in stone, and is short
enough to repeat to a friend.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` validates the entry against the bounty gate first
(UTF-8, 1–150 characters, not only white space, a single line)
and reads the file back to confirm it holds exactly the entry.
